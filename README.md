# Luis Alberto Reoyo Bolaños - Professional CV

A modern, responsive, and high-performance web-based Curriculum Vitae built with **Astro**.


## 🚀 Features

- **Multi-language Support**: Full i18n implementation (Spanish & English).
- **Dark Mode**: Integrated theme switcher with system preference detection and persistence.
- **Modern Tech Stack**: Built with Astro 5+, TypeScript, and Vanilla CSS.
- **Performance Optimized**: View Transitions and Prefetching enabled for instantaneous navigation.
- **Professional Design**: Glassmorphism effects, fluid transitions, and a clean typography system.

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Styling**: Vanilla CSS (Modern CSS Variables)
- **Icons**: SVG / Lucide-style
- **Deployment**: Optimized for GitHub Pages / Vercel / Netlify

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/lrb85/cv_luis_reoyo.git
   cd cv-luis
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

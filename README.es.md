# Luis Alberto Reoyo Bolaños - CV Profesional

Un Currículum Vitae web moderno, responsivo y de alto rendimiento construido con **Astro**.


## 🚀 Características

- **Soporte Multi-idioma**: Implementación completa de i18n (Español e Inglés).
- **Modo Oscuro**: Selector de tema integrado con detección de preferencia del sistema y persistencia.
- **Stack Tecnológico Moderno**: Construido con Astro 5+, TypeScript y CSS nativo.
- **Optimización de Rendimiento**: View Transitions y Prefetching habilitados para una navegación instantánea.
- **Diseño Profesional**: Efectos de glassmorphism, transiciones fluidas y un sistema tipográfico limpio.

## 🛠️ Stack Tecnológico

- **Framework**: [Astro](https://astro.build/)
- **Estilos**: Vanilla CSS (Variables CSS Modernas)
- **Iconos**: SVG / Estilo Lucide
- **Despliegue**: Optimizado para GitHub Pages / Vercel / Netlify

## 💻 Desarrollo Local

1. **Clona el repositorio**:
   ```bash
   git clone https://github.com/lrb85/cv_luis_reoyo.git
   cd cv-luis
   ```

2. **Instala las dependencias**:
   ```bash
   npm install
   ```

3. **Inicia el servidor de desarrollo**:
   ```bash
   npm run dev
   ```

4. **Compila para producción**:
   ```bash
   npm run build
   ```
